# 산업연관표 분석 웹앱 (2023년 한국 경제)

**작성자: 202110594 정준영** · 산업조직론 과제물 1

산업조직론 과제물 1 — GitHub Pages에 게시하는 산업연관표(투입산출표) 분석 웹앱입니다.
한국은행 2023년 투입산출표를 **대분류(33)·중분류(83)·소분류(165)·기본부문(380)** 네 가지 분류로 모두 불러와,
방문자의 브라우저 안에서 Python(Pyodide)으로 산업연관분석을 수행합니다. 별도 서버가 필요 없습니다.

- 계산 엔진: 브라우저의 Web Worker에서 실행되는 Pyodide 0.27.7 (numpy, openpyxl)

## 0. 이 앱을 만든 이유 (분석 목적)

한 산업에 생긴 변화는 거래로 연결된 다른 산업으로 번집니다. 이 앱은 **“이 산업은 누구에게서 사고 누구에게 파는가,
충격이 오면 어디까지 번지는가”**를 숫자로 확인하기 위해 만들었습니다. 증권사·자산운용사의 산업분석처럼 산업연관표를
투자·산업분석 도구로 쓰는 데 초점을 두었습니다.

- **투자·산업분석**: 산업 공급망 리포트로 한 산업의 공급처·판매처·수입 의존 원자재·수출 의존도를 한 화면에서 파악
- **경기 충격 점검**: 수출·투자·소비 변화가 산업별 생산·부가가치·임금에 주는 효과 (예: 수출 10% 감소)
- **비용 충격 점검**: 원유 등 수입가격·임금 상승이 산업별 가격과 물가에 전가되는 정도
- **분류 수준의 영향**: 같은 질문도 대분류로 보느냐 기본부문으로 보느냐에 따라 답이 달라짐을 확인

### 소·중·대분류 표 작성 방법

한국은행 부문분류 코드 체계에 따라 기본부문 거래표(백만원)의 **행과 열을 합산**한 뒤 계수를 다시 계산했습니다
(`scripts/build_tables.py`).

- 소분류 = 기본부문 코드 앞 3자리 (예: `3101 개별소자`, `3102 집적회로` → `310 반도체`)
- 중분류 = 기본부문 코드 앞 2자리 (예: `31 반도체`)
- 대분류 = 중분류 묶음 (예: `31~36` → `11 컴퓨터, 전자 및 광학기기`)

같은 계산식을 기본부문에 적용한 결과가 한국은행 공표 계수와 일치함을 확인했습니다(최대 절대오차: 국산투입계수 5.6×10⁻¹⁷,
생산유발계수 6.7×10⁻¹⁶, 최종수요 항목별 생산유발액 4.5×10⁻⁸백만원 — `data/build-report.json`).
분류별 총산출 합계는 네 표 모두 5,786.7조원으로 같습니다.
부문 명칭은 한국은행 부문분류표를 기준으로 정리했으며 공식 표기와 일부 다를 수 있습니다.

## 3. 사용 방법

1. **자료 불러오기** — 대분류·중분류·소분류·기본부문 카드의 "불러오기"를 누르거나 "네 가지 모두 불러오기"를 누릅니다.
   처음에는 Python 환경 준비에 20~40초, 기본부문(12MB)은 추가로 10~30초가 걸립니다.
   불러온 표 가운데 하나를 **분석 기준 분류**로 고르면 아래 분석이 그 분류로 계산됩니다.
   카드의 **“내 Excel 선택”**으로 LMS에서 받은 산업연관표 Excel을 직접 불러와 바꿔 끼울 수도 있습니다(파일은 브라우저 안에서만 읽힘).
   "계수 검증 결과 보기"에서 (I−Ad)L−I 잔차와 공표 생산유발계수와의 차이를 확인할 수 있습니다.
2. **원자료 탐색** — 시트를 고르고, 행 이름·코드로 검색해 한 행을 선택하면 그 행의 모든 열 값(열 코드·열 이름·값)이 표시됩니다.
   열 검색으로 특정 열(예: 수출, 총산출)만 볼 수 있으며, 시트마다 단위가 함께 표시됩니다.
3. **산업구조 한눈에 보기** — 총산출, 부가가치, 부가가치율, 피용자보수 비중, 수출 비중, 수입 의존도, 수입중간투입률,
   생산·부가가치·수입유발계수를 산업별로 비교합니다. 표 머리글을 누르면 정렬되고, 전체 지표를 CSV로 내려받을 수 있습니다.
4. **산업 공급망 리포트** — 산업 하나를 고르면 총산출·부가가치율·수출 비중·수입 의존도·생산유발계수(순위 포함),
   주요 국산 공급처와 수입 원자재(산출 1원당 투입), 주요 판매처(국산 판매액 대비 %), 최종수요별 판매 비중,
   이 산업 최종수요 1조원 증가 시 생산이 함께 늘어나는 산업을 보여주고 특징을 자동으로 해석해 줍니다.
   예) 반도체(중분류): 생산의 86%를 수출, 산출 1원당 수입 중간재 0.33원, 2023년 영업잉여 마이너스.
5. **최종수요 변화 시뮬레이션**
   - 산업별 금액 입력: 특정 산업의 국산품 최종수요 변화액(백만원, 감소는 음수)을 입력합니다.
   - 최종수요 항목 변화율: 예) `수출 · 전체 산업 · −10%`, `민간고정자본형성 · 비주거용 건물 · +5%`.
   - 결과: 생산·부가가치·수입·피용자보수 유발액, 생산유발승수, 2023년 부가가치 대비 비율, 산업별 결과표와 CSV.
6. **전후방 연관효과** — 영향력계수(가로)와 감응도계수(세로)의 산점도로 산업을 네 유형으로 나눕니다.
   사분면 카드를 누르면 해당 산업만 강조되고 표가 걸러집니다.
7. **가격파급효과** — 수입품 가격 상승(예: 원유 +10%)이나 부가가치 항목 상승(예: 전 산업 임금 +5%)이
   산업별 가격과 소비자물가·생산자물가(근사치)를 얼마나 올리는지 계산합니다.
8. **분류 수준별 결과 비교** — 같은 기본부문에 같은 금액의 수요가 생겼을 때 기본부문·소·중·대분류 표의 결과를 나란히 비교해
   산업을 묶을수록 생기는 통합 편의(aggregation bias)를 보여줍니다.
   예) 집적회로 1,000백만원 수요 증가 시 생산유발액이 기본부문 1,508백만원, 대분류(컴퓨터, 전자 및 광학기기) 1,718백만원으로 약 14% 차이.

## 4. 분석 방법

| 분석 | 식 | 해석 |
| --- | --- | --- |
| 국산투입계수 | Ad = Zd · diag(X)⁻¹ | 산출 1원당 국산 중간재 투입 |
| 생산유발계수 | L = (I − Ad)⁻¹ | 최종수요 1원 증가가 유발하는 산업별 생산 |
| 생산유발 | ΔX = L · ΔF | ΔF: 국산품 최종수요 변화(백만원) |
| 부가가치유발 | ΔV = diag(v) · L · ΔF | v: 산출 1원당 부가가치 |
| 수입유발 | ΔM = Am · L · ΔF | 중간재 수입 유발 (최종수요 직접 수입은 별도 표시) |
| 피용자보수 유발 | ΔW = diag(w) · L · ΔF | w: 산출 1원당 피용자보수 |
| 영향력계수 | L 열합 ÷ 열합 평균 | 1보다 크면 후방연관(원자재 수요 유발)이 평균보다 큼 |
| 감응도계수 | L 행합 ÷ 행합 평균 | 1보다 크면 전방연관(중간재 공급)이 평균보다 큼 |
| 가격파급 | Δp = (I − Ad′)⁻¹ Δc | Δc: 산출 1원당 비용 상승. 수입품 가격 상승률 r이면 Δcⱼ = Σₖ rₖ·Amₖⱼ |
| 소비자물가 근사 | (Σ Fdᶜ·Δp + Σ Fmᶜ·r) ÷ Σ(Fdᶜ + Fmᶜ) | 민간소비지출(국산+수입) 가중평균 |

### 한계

- 투입구조(계수)가 고정되어 있고 공급 제약이 없다고 가정하므로 단기·근사 분석입니다.
- 가격파급효과는 비용 상승분이 모두 가격에 전가되고, 유통마진·환율 변화 등 2차 효과는 반영하지 않습니다.
- 생산자가격 기준이므로 소비자가 실제 지불하는 구매자가격과는 차이가 있습니다.

## 5. GitHub Pages 게시 방법

1. GitHub에서 `+ → New repository` → 이름 입력, **Public**, Add README 켜기 → Create repository.
2. `Code` 탭 → `Add file → Upload files` → 이 폴더의 파일과 `data/`, `scripts/` 폴더를 끌어다 놓고 `Commit changes`.
   - 압축 파일은 반드시 풀어서 올립니다.
   - `.nojekyll`처럼 점(.)으로 시작하는 파일은 탐색기에서 숨겨져 업로드되지 않을 수 있습니다.
     그때는 `Add file → Create new file`에서 파일 이름을 `.nojekyll`로 적고 내용 없이 커밋하세요.
3. `Settings → Pages` → Source: **Deploy from a branch**, Branch: **main**, Folder: **/ (root)** → Save.
4. `Actions` 탭에서 배포 완료를 확인한 뒤 `https://<사용자이름>.github.io/<저장소이름>/`에 접속합니다.

시트 이름(`A표_총거래표(생산자)` 등)과 표 배치가 기본부문 파일과 같아야 하며, 불러올 때 공표 생산유발계수와 직접 계산한 값을
비교해 검증하므로 형식이 다르면 오류 메시지로 알려줍니다. 업로드 전에 웹앱의 “내 Excel 선택”으로 먼저 시험해 보세요.
